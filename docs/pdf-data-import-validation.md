# Trạng thái adapter PDF

Nguồn phụ lục cá tra của phiên bản đa loài đã được gỡ. src/data/pdf-facilities.json hiện rỗng; không có hồ sơ cơ sở/ao PDF nào tham gia demo lươn.

Giữ interface và adapter để tái sử dụng khi có nguồn **nuôi lươn** hợp lệ. Pipeline dữ liệu hiện hành nằm ở scripts/generate-eel-demo.mjs và scripts/build-eel-public-data.mjs.
